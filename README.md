# Проектные ассистенты — MVP

Облегчённая веб-оболочка для четырёх педагогических AI-ролей: Лидер, Технолог, Ассистент, Аналитик.

## Что уже есть

- Главная страница с четырьмя ролями.
- Поля имени ребёнка и названия проекта без регистрации.
- Отдельный чат для каждой роли.
- Независимая история на каждом устройстве/браузере через localStorage.
- Серверный вызов OpenAI Responses API — API-ключ не попадает в браузер.
- Ограничение передаваемой истории до последних 30 сообщений.
- Фундамент для следующего этапа: имя, проект, роль и диалог уже разделены сущностно.

## Что важно перед реальным использованием

В `lib/roles.js` находятся четыре блока `instructions`. Сейчас там временные педагогические инструкции-заглушки. Их нужно заменить точными Instructions ваших существующих GPT.

Если в GPT используются Knowledge-файлы, Actions или специальные инструменты, их нужно переносить отдельно — одних Instructions будет недостаточно.

## Локальный запуск

1. Установить Node.js 20+.
2. В папке проекта выполнить:

```bash
npm install
```

3. Скопировать `.env.example` в `.env.local` и вставить API-ключ:

```bash
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-5-mini
```

4. Запустить:

```bash
npm run dev
```

5. Открыть `http://localhost:3000`.

## Размещение

Проект подходит для Vercel. После импорта репозитория нужно добавить переменные окружения `OPENAI_API_KEY` и `OPENAI_MODEL` в настройках проекта.

## Одновременная работа детей

Каждый браузер хранит свою историю локально, поэтому разговоры детей не смешиваются. Один и тот же набор инструкций роли может обслуживать много независимых запросов. Реальная пропускная способность зависит от rate limits и бюджета вашего OpenAI API-проекта.
